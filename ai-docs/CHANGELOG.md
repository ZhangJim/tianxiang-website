# CHANGELOG.md

> AI 上下文文件 · 项目更新日志
> 用途：记录每次有意义的功能变更与上线。新对话开发前可快速看到「最近发生了什么」。

## 维护规则

- 每次有产品/功能/数据/规则变化时，在顶部追加一条
- 格式：`## YYYY-MM-DD`（按自然日聚合，单日多条用列表展开）
- 写**做了什么**，不写**怎么做**（不要贴代码）
- 涉及破坏性变更要标注 `⚠️ Breaking`
- 仅 UI 微调 / 文案订正可合并为单条「优化若干」
- 数据迁移 / CSV 字段变更 **必须单独列**

- 首页隐藏「合作伙伴」区块（代码保留，已用 JSX 注释包裹，便于后续恢复）
- 后台改造为 Tab 切换布局：「合作咨询」「AI 旅拍机点位」两个模块独立切换
- 后台表头吸顶、行 hover 高亮
- 后台表格新增**分页**（每页 20 条，含首页 / 上一页 / 下一页 / 末页）
- 后台「合作咨询」新增搜索框（按姓名 / 公司 / 手机号 / 产品过滤）
- 后台「点位」状态字段改为彩色标签（已覆盖 / 可咨询 / 洽谈中）
- 后台 Tab 去掉条数徽标，让顶部更清爽
- 后台表格斑马线加深（米色 / 浅米色交替），列表分组感更明显
- 后台「新增模式」按钮改名「取消修改」，默认隐藏，仅点击某条点位的「修改」后才出现（原始功能保留：用于退出修改态、避免误覆盖原数据）
- 后台表格行分隔线加深（米色实线），合作咨询与点位两个模块同步生效
- 后台点位操作列「修改 / 删除」按钮改为横向排列（`.row-actions` flex 容器）
- 修复：全局 `[hidden] { display: none !important }`，避免 `button { display: inline-flex }` 覆盖 HTML `hidden` 属性导致「取消修改」按钮无法默认隐藏
- 后台行分隔线进一步加深（`#c5af80`），偶行底色也加深（`#eed9b3`），列表分组更清晰
- 后台 `<head>` 加 no-cache meta，避免浏览器缓存旧版本 HTML 导致改动看不到
- 后台表格行线再加深至 `#a08054` 并加列边线，奇偶行对比强化（`#fffaf2` / `#e3c388`），形成明显网格
- 后台操作列按钮加双保险：`td.actions > button` 也强制 `inline-flex` 横排，避免 `.row-actions` 缓存不生效的边缘情况
- ⚠️ Breaking 修复：后台 `<style>` 改为 `<style is:global>`。原因：Astro 4 默认 scoped CSS 给静态元素加 `data-astro-cid-XXX` 属性、并把选择器改写成 `tbody td[data-astro-cid-XXX]`，但 JS 用 `innerHTML` 动态创建的表格行/按钮**没有这个属性**，导致所有动态生成元素的样式完全失效（行线看不见、按钮不能横排都是这个原因）。改 global 后样式立刻生效。后续凡是「DOM 由 JS 动态生成的页面」都必须用 `<style is:global>` 或外部 CSS 文件。
- 后台列表配色降饱和：偶行底色从刺眼的 `#e3c388` 改为柔和米色 `#f5ecd9`，悬浮色从 `#f3c891` 改为浅米橙 `#fbe6cf`，表头底色与行线同步调淡，整体更内敛、贴合米色品牌调
- 首页新增「核心技术能力」模块，位于「核心产品与场景」与「AI能力与服务」之间。2×2 卡片布局（移动端单列），4 张能力卡：大模型与推理 / 智能终端系统 / AI 基础设施 / 工程化平台。卡片含线性 SVG 图标（lucide 风格内联，不引入新依赖），悬停轻微上浮 + 科技蓝渐变描边 + 图标动效。组件 [`src/components/TechCapabilities.astro`](src/components/TechCapabilities.astro)，数据数组驱动，样式集中在 `global.css` 末尾的 `.tech-*` 模块
