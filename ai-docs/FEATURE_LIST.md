## 二、后台管理模块

### 1. 登录 `/admin/login/`
- 账号密码登录（来源：环境变量）
- Session 签名校验（`ADMIN_SESSION_SECRET`）

### 2. 后台首页 `/admin/`
- 顶部品牌区 + 打开官网 / 退出登录
- **Tab 切换**：合作咨询 / AI 旅拍机点位（带条数计数徽标）
- 每个面板独立呈现，互不干扰
- 公共能力：表头吸顶、行 hover 高亮、每页 20 条分页

### 3. 合作咨询查看
- 接口：`GET /api/admin/leads`
- 功能：
  - 只读列表查看
  - **搜索过滤**（按姓名 / 公司 / 手机号 / 咨询产品）
  - 分页（每页 20 条）
  - 导出 CSV
  - **不允许**编辑、删除
- 字段：提交时间 / 姓名 / 公司 / 手机号 / 咨询产品 / 来源 IP

### 4. 点位管理（AI 旅拍机）
- 接口：`/api/admin/locations`（GET / POST / PUT / DELETE / PATCH）
- 功能：
  - 列表查看
  - 搜索 / 过滤（城市 / 点位 / 关键词）
  - 分页（每页 20 条）
  - 新增点位
  - 修改点位
  - 删除点位
  - **批量导入 CSV**（追加导入 / 覆盖导入，支持字段别名）
  - 导出 CSV
- 字段：城市 / 点位名称 / 场景类型 / 设备类型 / 状态 / 说明 / 关键词
- 状态展示：彩色标签（已覆盖 / 可咨询 / 洽谈中）
- 写入机制：文件锁 + 自动备份 `.bak` + 临时文件原子替换

### 5. 退出登录
- 接口：`POST /api/admin/logout`
- 清理 Session

## 三、基础设施与跨模块能力

### 1. 统一布局
- `src/layouts/BaseLayout.astro`
- 注入：title / description / keywords / canonical / OG / Twitter / 结构化数据（Organization + WebSite）
- 顶部导航 + 商务咨询 CTA
- 页脚（品牌 + 联系信息 + 备案）

### 2. 通用组件（`src/components/`）
- `Hero.astro`：内页通用 Hero
- `SectionTitle.astro`：区块标题
- `CardGrid.astro`：通用卡片网格
- `ComputeTabs.astro`：算力服务三联 Tab

### 3. 数据层（`src/data/`）
- `site.ts` / `compute.ts` / `rental.ts` / `travelPhoto.ts` / `cardMachine.ts` / `aiCat.ts` / `terminals.ts` / `cases.ts`

### 4. 服务端工具（`src/lib/`）
- `csv.ts`：CSV 解析 / 序列化 / 文件锁 / 备份 / 原子写
- `adminAuth.ts`：后台登录 / Session
- `adminData.ts`：线索与点位读写、字段规范化、导入字段别名映射

### 5. SEO 能力
- 公共 SEO 字典：`src/data/site.ts` 的 `seo.pages`
- 全站关键词：`seo.keywords`
- 站点地图：`src/pages/sitemap.xml.ts`
- 爬虫规则：`src/pages/robots.txt.ts`

### 6. 部署能力
- `astro.config.mjs`：`output: "hybrid"` + Node standalone
- 入口：`node ./dist/server/entry.mjs`
- 默认端口 `4321`
- 推荐：PM2 + Nginx + HTTPS
